# Student User Guide

1. Sign in using the account created by the administrator.
2. View your enrolled courses and available assignments.
3. For each assignment, read the instructions, maximum mark and deadline information:
   - **Original deadline** is the deadline set when the lecturer created the assignment.
   - **Effective deadline** is the deadline that applies to you after any extension.
   - A personal extension takes precedence over a whole-class extension. If you have no personal extension, a whole-class extension applies. If neither exists, the original deadline applies.
4. Use the effective deadline when planning and submitting your work. The system uses that deadline when deciding whether a submission is late.
5. Submit the requested file using the file reference/path requested by the console prompt. Keep the file available in the expected submission location.
6. If resubmission is permitted, submit the updated work before the applicable deadline/window.
7. View released marks and lecturer feedback after the moderation and release process is complete.
8. Change your password when necessary and log out when finished.

A submitted mark may not be visible immediately: marks must pass through marking, moderation, approval and release. If the original and effective deadlines differ, use the effective deadline shown on your assignment list.
