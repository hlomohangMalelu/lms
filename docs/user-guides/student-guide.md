# Student User Guide

1. Sign in using the account created by the administrator.
2. View your enrolled courses and available assignments.
3. Read the assignment instructions, deadline and maximum mark.
4. Submit the requested file using the file reference/path requested by the console prompt. Keep the file available in the expected submission location.
5. If resubmission is permitted, submit the updated work before the applicable deadline/window.
6. View released marks and lecturer feedback after the moderation and release process is complete.
7. Change your password when necessary and log out when finished.

A submitted mark may not be visible immediately: marks must pass through marking, moderation, approval and release.
