# Administrator User Guide

## Sign in

Start the application from the project root and choose `1 Login`. Enter the administrator username and password. On a new database, use the initial credentials in the installation guide and change the password immediately.

## Administrator menu

| Option | Action |
|---|---|
| 1 | Create a department |
| 2 | Create a course and associate it with a department |
| 3 | Create a user and select `STUDENT`, `LECTURER`, `HOD`, or `ADMIN` |
| 4 | Register a student profile for an existing user |
| 5 | Register a lecturer profile for an existing user |
| 6 | Assign a user as head of a department |
| 7 | Assign a lecturer to a course |
| 8 | Enrol a student in a course |
| 9 | Deactivate a user account |
| 10 | List users |
| 11 | List courses |
| 12 | Change the signed-in user's password |
| 0 | Log out |

Create the user before registering their student or lecturer profile. Create departments and courses before assigning staff or enrolling students. Use the numeric IDs displayed by the application when linking records.

## Account safety

Use unique usernames and strong initial passwords (at least 12 characters). Deactivate accounts that should no longer access the system. Do not share administrator credentials.
