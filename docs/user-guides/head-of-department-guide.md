# Head of Department User Guide

1. Sign in using the HOD account assigned to your department by an administrator.
2. View marked submissions for your department.
3. Review the lecturer's mark and feedback.
4. Moderate the mark and record a meaningful moderation note.
5. Approve the moderated mark when it is acceptable.
6. Release approved marks so students can view them.
7. Change your password when necessary and log out when finished.

Moderation should be independent and traceable. Record clear reasons for changes or decisions, and do not release a mark before the required approval step.
